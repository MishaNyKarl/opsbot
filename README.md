# Opsbot

Telegram-бот для внутренних операционных уведомлений.

Что умеет:

- две роли: `admin` и `buyer`;
- регистрация пользователей через `/start`;
- подтверждение новых пользователей админом через кнопки;
- уведомление пользователю после подтверждения доступа;
- привязка аккаунтов Porkbun, Proxyline, Darkshopping и Datalix к баерам;
- самостоятельная настройка порога баланса баером;
- самостоятельная настройка уведомлений за N дней до окончания доменов или прокси;
- ручная проверка аккаунтов через кнопки;
- отдельный список истекших прокси и доменов по кнопке;
- ping-мониторинг серверов каждые 30 минут;
- подписки баеров на алерты по конкретным серверам;
- периодический мониторинг по расписанию.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Заполните `TELEGRAM_BOT_TOKEN`.
3. Укажите свой Telegram ID в `ADMIN_TELEGRAM_IDS`.
4. Запустите:

```bash
npm.cmd start
```

Внешние npm-пакеты не нужны. Проект использует Node.js 22 и встроенный `fetch`.

## Docker

Локальный запуск через Docker:

```bash
docker compose up -d --build
docker compose logs -f opsbot
```

Инструкция для сервера и GitHub Actions лежит в `deploy/README.md`.

## Как пользоваться

Пользователь пишет боту `/start`.

Если это первый админ из `ADMIN_TELEGRAM_IDS`, он сразу получает админское меню. Остальные пользователи попадают в статус ожидания.

Админ открывает:

```text
Админка -> Заявки на доступ -> Подтвердить пользователя
```

После подтверждения пользователю автоматически приходит сообщение, что доступ открыт.

Добавление аккаунта:

```text
Админка -> Баеры -> выбрать баера -> Добавить аккаунт -> выбрать сервис
```

После выбора сервиса бот попросит отправить данные одним сообщением:

```text
proxyline_main API_KEY
porkbun_main API_KEY SECRET_KEY
darkshopping_main API_KEY
datalix_main API_KEY
```

Настройка уведомлений баером:

```text
Мои аккаунты -> выбрать аккаунт -> Настроить баланс
Мои аккаунты -> выбрать аккаунт -> Настроить срок
```

Админ может смотреть аккаунты, запускать проверку и удалять привязки, но пороги уведомлений меняет владелец аккаунта.

В обычном отчете показываются только активные объекты с будущей датой окончания. Если есть истекшие прокси или домены, бот добавит кнопку `Показать истекшие`.

## Дефолтные уведомления

Если пороги не заданы вручную, бот выставляет их сам:

- Porkbun: баланс ниже `10 USD`;
- Proxyline: баланс ниже `10 RUB`, срок прокси `3` дня;
- Darkshopping: баланс ниже `2000 RUB`.
- Datalix: уведомление об оплате за `2` дня до `expire_at`.

Пока баланс ниже порога, баер получает не больше одного уведомления в день по каждому аккаунту. По сроку прокси уведомление тоже приходит не чаще одного раза в день по каждому объекту.

Для Datalix бот также проверяет `status` каждого сервера. Если сервер вернулся со статусом `error`, баер получает отдельный alert не чаще одного раза в день по серверу.

## Ping-мониторинг серверов

Админ может добавить IP или hostname сервера:

```text
Главное меню -> Серверы -> Добавить сервер
```

Формат ввода:

```text
server_name 192.0.2.10
```

Бот проверяет серверы ICMP ping каждые 30 минут. Если сервер стал недоступен, уведомление получают все активные админы и пользователи, которые подписались на этот сервер. Когда сервер восстановился, бот также отправляет уведомление.

Баер может сам подписаться:

```text
Главное меню -> Серверы -> выбрать сервер -> Подписаться на алерты
```

В карточке сервера есть кнопка `Проверить сейчас`, чтобы не ждать очередного 30-минутного цикла.

## Настройки

`.env`:

```text
TELEGRAM_BOT_TOKEN=123456:replace_me
ADMIN_TELEGRAM_IDS=123456789,987654321
CHECK_INTERVAL_MINUTES=60
DATA_FILE=./data/opsbot.json
```

`CHECK_INTERVAL_MINUTES` отвечает за частоту автоматической проверки.

## Важно

- Porkbun возвращает баланс в центах USD, бот показывает его в долларах.
- Proxyline в документации не фиксирует точный формат ответа баланса, поэтому парсер сделан терпимым к разным JSON-форматам.
- Proxyline предупреждает о правилах перепродажи. Этот бот сделан для внутренних уведомлений и мониторинга, без оформления заказов и перепродажи через Telegram.
